Initial release.

## Includes

- Self-contained macOS menu bar app
- One-click Universal Control restart
- Auto-installed watchdog LaunchAgent
- Watchdog log access from the menu bar
- English and Traditional Chinese README files

## Install

1. Download `Universal-Control-Restarter.zip`
2. Unzip it
3. Move `Universal Control Restarter.app` to `/Applications`
4. Right-click `Open` the first time if Gatekeeper warns
